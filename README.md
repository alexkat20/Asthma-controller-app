# Peak Flow — веб-чат-бот для контроля астмы

Веб-приложение (FastAPI + чат-интерфейс в браузере, без Telegram), которое можно
открыть на телефоне или компьютере и пользоваться как обычным чатом.

## Возможности

1. **Профиль пользователя** — при первом обращении бот один раз проводит короткую
   анкету (пол, возраст, рост, вес, курение, город, аллергия на пыльцу — только на
   те растения, которые реально можем мониторить). Дальше не повторяется;
   посмотреть/обновить — командой «профиль» / «изменить профиль».
2. Запись показаний одним свободным сообщением — NLP-парсер сам находит цифры,
   препараты, дозы и состояние («450 460 470 сальбутамол 2 дозы, спорт»).
3. Зоны (зелёная/жёлтая/красная) считаются по персональному рекорду в скользящем
   90-дневном окне, а не по последним N записям подряд.
4. Анализ и графики за неделю / 2 недели / месяц / квартал / год / произвольный
   диапазон дат (ДД.ММ.ГГГГ-ДД.ММ.ГГГГ).
5. Прогноз на сегодня и на неделю вперёд: тренд + сезонность по дню недели +
   эффект вчерашних состояний (спорт/стресс/аллергия/болезнь/перелёт).
6. При попадании в жёлтую/красную зону бот подбирает препарат на основе истории —
   какой препарат чаще ассоциировался с возвратом в зелёную зону на следующий
   день. Это статистика по вашим же данным, а не медицинская рекомендация — так
   и подписано в ответе.
7. Данные о пыльце/аллергенах через бесплатный Open-Meteo Air Quality API (без
   ключа, покрытие — Европа): команда «город Москва» задаёт регион, «аллергия» —
   проверка сейчас, а утренний дайджест включает сводку по пыльце вместе с
   прогнозом пикфлоу. Если в профиле указаны свои аллергены — именно они
   выделяются в сводке в первую очередь.
8. Импорт истории из CSV/Excel (кнопка загрузки в интерфейсе).
9. Ежедневные напоминания и фоновые уведомления об ухудшении зоны (поллинг, без
   push-сервисов).

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Открыть в браузере: http://localhost:8000

При первом открытии в браузере создаётся уникальный `user_id` (в `localStorage`),
поэтому несколько человек могут пользоваться одним и тем же запущенным сервером
независимо друг от друга.

## Структура проекта (слоями)

```
main.py                    — сборка FastAPI-приложения: роутеры, статика, планировщик
models/
  domain.py                 — доменные структуры (ZoneThresholds)
  schemas.py                 — Pydantic-схемы запросов/ответов API
repositories/                — весь SQL и работа с БД, больше никто в БД не ходит
  database.py                 — схема, зоны, импорт файлов, CRUD показаний/препаратов
  profile_repository.py       — анкета пользователя (user_profile)
  settings_repository.py      — город (для пыльцы) и напоминания
services/                    — бизнес-логика
  nlp_service.py               — определение состояния и разбор свободного текста
  forecast_service.py          — прогноз на сегодня и неделю
  recommend_service.py         — подбор препарата на основе истории
  allergy_service.py           — клиент Open-Meteo (геокодинг + пыльца)
  analytics_service.py         — анализ за период, график, прогноз (текст + картинки)
  logging_service.py           — умная запись показаний (NLP -> БД -> рекомендация)
  medicine_service.py          — добавление/обновление препарата
  profile_service.py           — онбординг анкеты (шаг за шагом, один раз)
  location_service.py          — город <-> координаты, проверка аллергии
  reminder_service.py          — команда напоминания + фоновый планировщик дайджеста
  notification_service.py      — очередь уведомлений для поллинга фронтендом
  chat_service.py               — верхнеуровневый роутинг сообщений чата
endpoints/                    — тонкие HTTP-роутеры FastAPI (вызывают services)
  chat.py, upload.py, notifications.py
utils/                        — общие мелочи без побочных эффектов
  dates.py                     — периоды/диапазоны дат
  formatting.py                — переводы (зоны/флаги/пол/курение), тексты, меню
  plotting.py                   — рендер matplotlib-графика в base64 data-URI
static/                        — фронтенд (HTML/CSS/JS, без фреймворков)
```
