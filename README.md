# Peak Flow — веб-чат-бот для контроля астмы

Больше не Telegram-бот: веб-приложение (FastAPI + чат-интерфейс в браузере), которое
можно открыть на телефоне или компьютере, добавить на домашний экран и пользоваться
как обычным чатом.

## Возможности

1. Запись показаний одним свободным сообщением — NLP-парсер (`nlp.py`) сам находит
   цифры, препараты, дозы и состояние («450 460 470 сальбутамол 2 дозы, спорт»).
2. Зоны (зелёная/жёлтая/красная) считаются по персональному рекорду в скользящем
   90-дневном окне (`db.py`), а не по последним N записям подряд.
3. Анализ и графики за неделю / 2 недели / месяц / квартал / год / произвольный
   диапазон дат (ДД.ММ.ГГГГ-ДД.ММ.ГГГГ).
4. Прогноз на сегодня и на неделю вперёд (`forecast.py`): тренд + сезонность по
   дню недели + эффект вчерашних состояний (спорт/стресс/аллергия/болезнь/перелёт).
5. Импорт истории из CSV/Excel (кнопка загрузки в интерфейсе).
6. Ежедневные напоминания и фоновые уведомления об ухудшении зоны (поллинг, без
   push-сервисов).

## Запуск

```bash
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Открыть в браузере: http://localhost:8000

При первом открытии в браузере создаётся уникальный `user_id` (в `localStorage`),
поэтому несколько человек могут пользоваться одним и тем же запущенным сервером
независимо друг от друга.

## Структура проекта

- `app.py` — веб-бэкенд (FastAPI): маршрутизация сообщений, анализ, графики,
  прогноз, загрузка файлов, напоминания.
- `db.py` — схема БД (SQLite), расчёт зон, импорт файлов.
- `nlp.py` — определение состояния и разбор свободного текста.
- `forecast.py` — прогноз на сегодня и неделю.
- `static/` — фронтенд (чат-интерфейс: HTML/CSS/JS, без фреймворков).
